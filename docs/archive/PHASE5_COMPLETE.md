## 🎯 功能特性

### 核心功能
✅ **报告申请** - 5种报告类型，灵活的申请表单  
✅ **配额管理** - 2份/月，自动重置  
✅ **状态跟踪** - 完整的状态流转和时间线  
✅ **文件管理** - 安全的文件上传下载  
✅ **权限控制** - 订阅验证、配额限制  

### 报告类型（5种）
1. **技术路线优化**
   - 分析不同技术方案的经济性和可行性
   - 示例：煤制油与绿氢耦合经济性对比

2. **区域市场布局**
   - 分析特定区域的市场机会和布局建议
   - 示例：蒙西电网消纳能力分析

3. **政策影响分析**
   - 深度解读政策对企业的影响
   - 示例：双碳政策对煤化工企业的影响

4. **竞争对手分析**
   - 分析主要竞争对手的战略和动向

5. **投资决策支持**
   - 为重大投资决策提供数据支持

### 申请流程
```
用户填写申请表单
    ↓
系统检查配额
    ↓
提交申请（消耗配额）
    ↓
管理员审核
    ↓
分配编写人员
    ↓
报告编写
    ↓
上传报告文件
    ↓
用户下载报告
```

### 状态流转
```
pending → assigned → in_progress → completed
   ↓
rejected
```

## 🚀 使用流程

### 1. 申请报告
1. 进入定制报告页面
2. 查看剩余配额
3. 点击"申请报告"
4. 选择报告类型
5. 填写需求描述
6. 提交申请

### 2. 查看进度
1. 在报告列表查看申请
2. 点击"查看详情"
3. 查看状态时间线
4. 等待报告完成

### 3. 下载报告
1. 报告完成后收到通知
2. 进入报告详情页
3. 在报告文件列表中
4. 点击"下载"按钮
