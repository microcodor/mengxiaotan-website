**版本**: 1.0

## 📋 功能概述

数字分身沙盘是基于企业公开数据构建的模拟系统，能够模拟政策变化、价格波动等外部因素对企业经营指标的影响，帮助企业进行战略决策和风险评估。

---

## 🎯 核心价值

### 用户价值
- **战略决策支持** - 模拟不同场景下的经营结果
- **风险评估** - 提前识别潜在风险和机会
- **数据驱动** - 基于真实数据的科学决策
- **可视化展示** - 直观的图表和报告

### 业务价值
- **差异化服务** - 提供独特的企业服务
- **用户粘性** - 增强用户对平台的依赖
- **数据积累** - 积累行业数据和模型
- **商业价值** - 基础版核心功能

## 🔧 功能需求

### 1. 数据模型构建

#### 1.1 企业财务模型
**需求**: 基于企业公开数据构建财务模型

**输入数据**:
- 企业基本信息（规模、行业、地区）
- 业务数据（主营业务、产能、产量）
- 财务假设（成本结构、利润率）

**输出指标**:
- 营业收入
- 营业成本
- 毛利润
- 净利润
- ROE（净资产收益率）
- ROI（投资回报率）

**计算公式**:
```
营业收入 = 产量 × 产品价格
营业成本 = 原材料成本 + 人工成本 + 能源成本 + 其他成本
毛利润 = 营业收入 - 营业成本
净利润 = 毛利润 - 税费 - 财务费用
ROE = 净利润 / 净资产
ROI = (收益 - 投资) / 投资
```

#### 1.2 政策影响模型
**需求**: 模拟政策变化对企业的影响

**政策类型**:
1. **碳税政策**
   - 参数：碳税税率（元/吨CO2）
   - 影响：增加碳排放成本
   - 计算：碳税成本 = 碳排放量 × 碳税税率

2. **补贴政策**
   - 参数：补贴类型、补贴额度
   - 影响：减少成本或增加收入
   - 计算：补贴收入 = 符合条件的项目 × 补贴额度

3. **配额政策**
   - 参数：配额数量、超额惩罚
   - 影响：限制产能或增加成本
   - 计算：超额成本 = (实际排放 - 配额) × 惩罚单价

4. **电价政策**
   - 参数：电价调整幅度
   - 影响：改变能源成本
   - 计算：能源成本变化 = 用电量 × 电价变化

#### 1.3 价格波动模型
**需求**: 模拟价格变动对企业的影响

**价格类型**:
1. **原材料价格**
   - 煤炭价格
   - 天然气价格
   - 石油价格
   - 其他原材料

2. **产品价格**
   - 电力价格
   - 化工产品价格
   - 其他产品价格

3. **能源价格**
   - 电价
   - 气价
   - 热价

**波动幅度**:
- ±5%、±10%、±20%、±30%
- 自定义幅度

**影响计算**:
```
成本变化 = 原材料用量 × 价格变化
收入变化 = 产品销量 × 价格变化
利润变化 = 收入变化 - 成本变化
```

### 2. 模拟引擎

#### 2.1 场景配置
**需求**: 用户可以配置模拟场景参数

**配置项**:
- 场景名称
- 场景描述
- 模拟时间范围（1年、3年、5年）
- 政策参数
- 价格参数
- 其他假设

**示例场景**:
```json
{
  "name": "双碳政策影响分析",
  "description": "模拟碳税政策对企业利润的影响",
  "time_range": "3年",
  "policies": [
    {
      "type": "carbon_tax",
      "rate": 50,
      "unit": "元/吨CO2"
    }
  ],
  "prices": [
    {
      "type": "coal",
      "change": 10,
      "unit": "%"
    }
  ]
}
```

#### 2.2 模拟计算
**需求**: 根据场景参数计算模拟结果

**计算步骤**:
1. 加载企业基础数据
2. 应用政策影响
3. 应用价格变化
4. 计算财务指标
5. 生成时间序列数据

**输出结果**:
```json

    "profit": 150000000,

    "roi": 9.2

  "impact": {
    "revenue_change": 0,
    "cost_change": 50000000,
    "profit_change": -50000000,
    "roe_change": -3.9,
    "roi_change": -3.1

  "time_series": [
    {
      "year": 1,

      "roe": 13.9

    {
      "year": 2,

      "roe": 12.8

      "roe": 11.6
```

## 📊 数据库设计

### simulation_scenarios 表（模拟场景）
```sql
CREATE TABLE simulation_scenarios (
    id INT PRIMARY KEY AUTO_INCREMENT,
    company_id INT NOT NULL,
    user_id INT NOT NULL,
    name VARCHAR(100) NOT NULL,
    description TEXT,
    time_range INT DEFAULT 3,  -- 模拟年限
    config JSON NOT NULL,  -- 场景配置
    status VARCHAR(20) DEFAULT 'draft',  -- draft, running, completed, failed
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (company_id) REFERENCES companies(id),
    FOREIGN KEY (user_id) REFERENCES users(id)
);
```

### simulation_results 表（模拟结果）
```sql
CREATE TABLE simulation_results (
    id INT PRIMARY KEY AUTO_INCREMENT,
    scenario_id INT NOT NULL,
    base_case JSON NOT NULL,  -- 基准情况
    simulated_case JSON NOT NULL,  -- 模拟情况
    impact JSON NOT NULL,  -- 影响分析
    time_series JSON NOT NULL,  -- 时间序列数据
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (scenario_id) REFERENCES simulation_scenarios(id)
);
```
