## 🎯 核心功能实现

### 1. 企业画像服务类 (CompanyProfileService)

**文件**: `backend/app/services/company_profile_service.py`

**核心方法**:

#### 1.1 画像构建
```python
build_company_profile(company_id) -> Dict
```
- 收集企业基础信息
- 分析核心竞争力
- 识别风险
- 识别机会
- 计算综合评分

#### 1.2 竞争力分析
```python
_analyze_competitiveness(company, basic_info) -> Dict
```
**分析维度**:
- 规模优势（员工数、营收）
- 业务多元化程度
- 市场地位和份额
- 行业定位
- 地理位置优势

**评分规则**:
- 员工≥1000人：8分
- 员工≥500人：6分
- 业务≥3项：7分
- 能源行业：8分
- 资源丰富省份：7分

#### 1.3 风险识别
```python
_identify_risks(company, basic_info) -> Dict
```
**风险类型**:
1. **环保风险**
   - 高污染行业（煤炭、钢铁、化工）
   - 环保合规成本

2. **产能过剩风险**
   - 煤炭、钢铁、水泥、电解铝
   - 产能结构优化需求

3. **政策风险**
   - 双碳目标压力
   - 传统能源转型

4. **市场风险**
   - 能源价格波动
   - 盈利能力影响

**风险等级**:
- High: 高风险≥2个
- Medium: 高风险≥1个 或 中风险≥3个
- Low: 其他情况

#### 1.4 机会识别
```python
_identify_opportunities(company, basic_info) -> Dict
```
**机会类型**:
1. **政策机会**
   - 新能源政策支持
   - 双碳目标机遇
   - 节能环保产业

2. **市场机会**
   - 能源转型机会
   - 区域市场潜力
   - 外送通道拓展

3. **技术机会**
   - 数字化转型
   - AI算力需求
   - 智能化改造

**机会等级**:
- High: 高潜力机会≥3个
- Medium: 高潜力机会≥1个
- Low: 其他情况

#### 1.5 综合评分
```python
_calculate_overall_score(competitiveness, risks, opportunities) -> int
```
**评分公式**:
```
综合评分 = 竞争力得分 × 40% + 风险得分 × 30% + 机会得分 × 30%
```

**评级标准**:
- 80-100分：优秀
- 60-79分：良好
- 40-59分：一般
- 0-39分：较差

### 2. 企业画像API

**文件**: `backend/app/api/company_profile.py`

#### 2.1 获取完整画像
**GET /api/company-profile/{company_id}**

**权限要求**:
- 需要基础版订阅
- 只能查看自己公司的画像
- 管理员可查看所有画像

**响应示例**:
```json
{
  "success": true,
  "data": {
    "company_id": 1,
    "company_name": "测试能源集团",
    "overall_score": 90,
    "basic_info": {...},
    "competitiveness": {
      "score": 100,
      "strengths": [...],
      "core_capabilities": [...]
    },
    "risks": {
      "overall_risk_level": "low",
      "environmental_risks": [...],
      "capacity_risks": [...],
      "policy_risks": [...],
      "market_risks": [...]
    },
    "opportunities": {
      "overall_opportunity_level": "medium",
      "policy_opportunities": [...],
      "market_opportunities": [...],
      "technology_opportunities": [...]
    },
    "summary": "【企业画像摘要】..."
  }
}
```

#### 2.2 获取画像摘要
**GET /api/company-profile/{company_id}/summary**

快速预览，返回关键指标和摘要。

#### 2.3 导出画像报告
**GET /api/company-profile/{company_id}/export?format=json**

支持格式：
- json（已实现）
- pdf（待实现）
- word（待实现）
