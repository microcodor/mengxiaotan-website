# 文章管理功能增强报告

## 📋 完成的功能

### 1. 爬虫入库文章默认审核通过 ✅

**修改文件**: `crawler/energy_crawler/pipelines.py`

**变更内容**:
- 在 `DatabasePipeline.process_item()` 方法中添加 `is_reviewed` 字段
- 爬虫入库的文章自动设置为 `is_reviewed=True`
- 日志信息更新为 "Article saved (auto-reviewed)"

**代码变更**:
```python
# 插入SQL增加 is_reviewed 字段
sql = """
    INSERT INTO articles 
    (title, summary, content, source, source_url, category, tags, published_at, created_at, is_reviewed)
    VALUES (%s, %s, %s, %s, %s, %s, %s, %s, %s, %s)
"""

# 执行时传入 True
self.cursor.execute(sql, (
    # ... 其他字段
    True  # 爬虫入库的文章默认审核通过
))
```

**影响范围**:
- 所有通过Scrapy爬虫入库的文章都会自动审核通过
- 不影响手动创建的文章
- crawl4ai_base.py 中的爬虫已经有类似设置

#### 2.2 后端API增强

##### GET /admin/articles
**新增查询参数**:
- `page`: 页码（默认1）
- `per_page`: 每页数量（默认20）
- `keyword`: 关键词搜索
- `category`: 分类筛选
- `status`: 状态筛选（reviewed/pending）

**返回格式**:
```json
{
  "items": [...],
  "total": 1234,
  "page": 1,
  "per_page": 20,
  "pages": 62
}
```

##### POST /admin/articles/batch-review
**功能**: 批量审核文章

**请求体**:
```json
{
  "ids": [1, 2, 3, 4, 5]
}
```

**返回**:
```json
{
  "message": "已审核 5 篇文章"
}
```

##### POST /admin/articles/batch-delete
**功能**: 批量删除文章

**请求体**:
```json
{
  "ids": [1, 2, 3, 4, 5]
}
```

**返回**:
```json
{
  "message": "已删除 5 篇文章"
}
```

##### DELETE /admin/articles/:id
**功能**: 删除单篇文章（已修复）

**返回**:
```json
{
  "message": "删除成功"
}
```

#### 2.3 操作日志记录

所有管理操作都会记录到 `operation_logs` 表：
- 批量审核: `batch_review_articles`
- 批量删除: `batch_delete_articles`
- 单个删除: `delete_article`
- 记录操作人、时间、详情

## 📊 数据流

### 搜索流程
```
用户输入关键词 → 点击搜索 → 
前端发送请求 → 后端SQL LIKE查询 → 
返回匹配结果 → 前端渲染列表
```

### 批量操作流程
```
用户选择文章 → 点击批量操作 → 
确认对话框 → 发送ID数组 → 
后端批量更新/删除 → 记录日志 → 
返回成功消息 → 刷新列表 → 显示Toast
```

## 🚀 使用指南

### 搜索文章
1. 在搜索框输入关键词
2. 按Enter或点击"搜索"按钮
3. 系统会搜索标题和内容中包含关键词的文章

### 筛选文章
1. 选择分类下拉框，选择特定分类
2. 选择状态下拉框，筛选已审核或待审核
3. 可以组合使用搜索和筛选

### 批量审核
1. 勾选需要审核的文章（可以点击表头全选）
2. 点击"批量审核"按钮
3. 确认后，所有选中的文章将被标记为已审核

### 批量删除
1. 勾选需要删除的文章
2. 点击"批量删除"按钮
3. 确认后，所有选中的文章将被永久删除

### 单个操作
- 👁 查看：跳转到文章详情页
- ✓ 审核：将文章标记为已审核（仅待审核文章显示）
- 🗑 删除：删除该文章（需确认）

---

## ⚠️ 注意事项

1. **删除操作不可恢复**
   - 删除前会弹出确认对话框
   - 建议定期备份数据库

2. **批量操作限制**
   - 建议每次批量操作不超过100篇文章
   - 大量操作可能需要较长时间

3. **搜索性能**
   - 关键词搜索使用LIKE查询
   - 建议为title和content字段添加全文索引

4. **权限要求**
   - 所有操作需要管理员或编辑权限
   - 操作会记录到操作日志
