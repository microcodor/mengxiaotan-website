## 🔧 清理SQL

### 完整清理脚本

```sql
START TRANSACTION;

-- 1. 删除关联的用户历史记录
DELETE uh FROM user_history uh
WHERE uh.article_id IN (
    SELECT id FROM articles 
    WHERE source = '国家发改委' AND content LIKE '%HTTP Status 404%'
);

-- 2. 删除404文章
DELETE FROM articles 
WHERE source = '国家发改委' AND content LIKE '%HTTP Status 404%';

COMMIT;
```
