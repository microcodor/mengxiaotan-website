## 问题分析

### 发现的问题

1. **抓取了大量栏目页和分类页**
   - 【天然气】、【石油】、【储能】、【综合】等栏目页
   - 政策与经济、油气、煤炭、电力、新能源等分类页
   - 这些不是真正的文章，而是导航页面

2. **数据统计**
   - 优化前：48篇文章
   - 其中无效文章：29篇（60%）
   - 真实文章：19篇（40%）

3. **URL类型分布**
   - 文章页（/news/news-数字-1.html）：19篇 ✅
   - 栏目页（/news/power/、/news/oil-gas/等）：9篇 ❌
   - 分类页（/power/、/oil-gas/等）：19篇 ❌
   - 其他：1篇 ❌

### 问题原因

**原爬虫代码**:
```python
def extract_from_markdown(self, result):
    # 从内部链接中提取
    for link in result.links.get('internal', []):
        href = link.get('href', '')
        text = link.get('text', '')
        
        # 过滤无效链接
        if not href or not text:
            continue
        
        # 过滤导航链接
        if any(skip in href.lower() for skip in ['javascript:', '#', 'mailto:']):
            continue
        
        # 过滤非文章链接
        if any(skip in href.lower() for skip in ['/data/', '/market/', '/trade/']):
            continue
        
        articles.append({
            'title': text.strip(),
            'url': href,
            'published_date': None
        })
```

**问题**:
- 过滤条件太宽松
- 没有检查URL格式
- 没有过滤栏目页和分类页

## 优化后的代码

```python
def extract_from_markdown(self, result):
    """从Markdown提取链接 - 只保留真正的文章链接"""
    articles = []
    
    if not result.markdown or not result.links:
        return articles
    
    # 从内部链接中提取
    for link in result.links.get('internal', []):
        href = link.get('href', '')
        text = link.get('text', '')
        
        if not text or not href:
            continue
        
        text = text.strip()
        
        # 只保留真正的文章链接
        # 文章链接格式: /news/news-数字-1.html
        if '/news/news-' in href and href.endswith('.html'):
            # 过滤掉明显的导航链接和栏目页
            if not any(skip in text for skip in [
                '首页', '关于', '联系', '更多', '返回', '登录', '注册',
                '政策与经济', '油气', '煤炭', '电力', '新能源', '节能环保',
                '【', '】', 'English', '网站地图', '资讯', '新闻'
            ]):
                # 标题长度合理
                if 10 < len(text) < 100:
                    articles.append({
                        'title': text,
                        'url': href,
                        'published_date': None
                    })
    
    return articles
```

### ✅ 成功经验

1. **严格的URL格式检查**

   - 避免抓取导航页和分类页

2. **多层过滤机制**

3. **及时数据清理**
   - 发现问题后立即清理无效数据

### 📝 经验教训

1. **初始过滤不够严格**
   - 应该在爬虫开发阶段就做好过滤
   - 避免抓取大量无效数据

2. **需要定期检查数据质量**
   - 定期抽查文章标题和内容
   - 及时发现和修复问题

3. **URL模式识别很重要**
   - 不同类型的页面有不同的URL模式
   - 需要准确识别文章页的URL模式
