## 📊 系统定时任务

当前系统共有 **6个定时任务**:

| # | 任务名称 | 执行时间 | 类型 | 功能 |
|---|---------|---------|------|------|
| 1 | 早间爬虫任务 | 每天 08:00 | 🔵 爬虫 | 运行所有爬虫 |
| 2 | 午间爬虫任务 | 每天 12:00 | 🔵 爬虫 | 运行所有爬虫 |
| 3 | 晚间爬虫任务 | 每天 18:00 | 🔵 爬虫 | 运行所有爬虫 |
| 4 | 每日AI简报生成 | 每天 09:00 | 🟣 AI简报 | 生成昨日简报 |
| 5 | 检查试用期到期 | 每天 08:00 | 🟡 订阅 | 发送到期提醒 |
| 6 | 处理过期试用订阅 | 每天 01:00 | 🟡 订阅 | 标记过期订阅 |

## 🎯 核心功能

### 1. 查看定时任务
- 📋 显示所有任务的详细信息
- 🏷️ 任务类型标签(颜色区分)
- 📊 运行状态实时显示
- ⏰ 下次运行时间
- 🔧 触发器配置

### 2. 暂停任务 ⏸️
- 临时停止任务自动执行
- 状态变为"已暂停"
- 下次运行时间消失
- 适用于系统维护

### 3. 恢复任务 ▶️
- 恢复已暂停的任务
- 状态变为"运行中"
- 显示下次运行时间
- 任务恢复自动执行

### 4. 立即执行 ⚡
- 手动触发任务执行
- 不影响定时计划
- 可在实时进度中监控
- 适用于测试和紧急更新

## 🚀 使用方法

### 快速开始
1. 登录管理后台
2. 访问 `http://localhost:5173/admin/crawler`
3. 点击 **"定时任务"** 标签页
4. 查看和控制所有定时任务

### 常用操作
```bash
# 暂停任务
1. 找到要暂停的任务
2. 点击"暂停"按钮
3. 确认状态变为"已暂停"

# 恢复任务
1. 找到已暂停的任务
2. 点击"恢复"按钮
3. 确认状态变为"运行中"

# 立即执行
1. 找到要执行的任务
2. 点击"立即执行"按钮
3. 切换到"实时进度"查看执行情况
```

## 💡 使用场景

### 场景1: 系统维护
```
需求: 进行数据库维护,需要暂停所有爬虫

步骤:
1. 访问定时任务页面
2. 暂停 morning_crawl
3. 暂停 noon_crawl
4. 暂停 evening_crawl
5. 进行数据库维护
6. 维护完成后逐个恢复任务
```

### 场景2: 测试新爬虫
```
需求: 添加了新爬虫,想立即测试

步骤:
1. 点击 morning_crawl 的"立即执行"
2. 切换到"实时进度"标签页
3. 观察新爬虫的执行情况
4. 在"爬取日志"中查看详细日志
```

### 场景3: 紧急数据更新
```
需求: 需要立即抓取最新数据

步骤:
1. 点击相应任务的"立即执行"
2. 任务立即开始执行
3. 不影响原有的定时计划
```
