## 🎯 功能特性

### 核心功能
✅ **场景配置** - 灵活的政策和价格参数配置  
✅ **模拟计算** - 精确的财务指标计算  
✅ **结果展示** - 直观的图表和数据展示  
✅ **场景对比** - 多场景并行对比分析  
✅ **趋势预测** - 1-5年的时间序列预测  

### 支持的模拟类型

#### 政策模拟（4类）
1. **碳税政策**
   - 参数：碳税税率（元/吨CO2）
   - 影响：增加碳排放成本

2. **补贴政策**
   - 参数：补贴类型、补贴标准
   - 影响：增加收入

3. **配额政策**
   - 参数：配额数量、超额惩罚
   - 影响：限制排放或增加成本

4. **电价政策**
   - 参数：电价变化百分比
   - 影响：改变能源成本

#### 价格模拟（3类）
1. **产品价格变化**
   - 影响：改变营业收入

2. **原材料价格变化**
   - 影响：改变原材料成本

3. **能源价格变化**
   - 影响：改变能源成本

### 预设模板（5个）
1. 碳税政策影响分析
2. 煤炭价格上涨影响
3. 新能源补贴政策
4. 双碳政策综合影响
5. 能源价格波动影响

## 🎯 核心算法示例

### 碳税政策影响
```
企业年产量: 425万吨
碳排放系数: 2.5吨CO2/吨产品
碳税税率: 50元/吨CO2

碳排放量 = 425万 × 2.5 = 1062.5万吨CO2
碳税成本 = 1062.5万 × 50 = 5.31亿元
利润影响 = -5.31亿元（约-25%）
```

### 原材料价格上涨
```
原材料成本: 95.6亿元
价格上涨: 20%

成本增加 = 95.6亿 × 20% = 19.1亿元
利润影响 = -19.1亿元（约-40%）
```

### 新能源补贴
```
年产量: 425万吨
补贴标准: 100元/吨

补贴收入 = 425万 × 100 = 4.25亿元
利润影响 = +4.25亿元（约+20%）
```
