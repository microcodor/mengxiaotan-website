# 定时任务管理使用指南

## 📖 功能概述

定时任务管理功能允许管理员查看和控制系统中的所有定时任务,包括爬虫任务、AI简报生成、订阅管理等。

---

## 🚀 快速开始

### 1. 访问定时任务管理页面

1. 登录管理后台
2. 访问 `http://localhost:5173/admin/crawler`
3. 点击顶部的 **"定时任务"** 标签页

### 2. 查看定时任务列表

页面会显示所有定时任务,包括:
- 📋 任务名称和ID
- 🏷️ 任务类型(爬虫/AI简报/订阅管理)
- 📊 运行状态(运行中/已暂停)
- ⏰ 下次运行时间
- 🔧 触发器配置

---

## 🎮 任务控制操作

### 暂停任务 ⏸️

**使用场景**:
- 临时停止某个定时任务
- 维护期间暂停爬虫
- 调试时避免任务干扰

**操作步骤**:
1. 找到要暂停的任务
2. 点击右侧的 **"暂停"** 按钮
3. 确认状态变为 **"已暂停"**
4. 任务将不再自动执行

**效果**:
- ✅ 任务立即停止自动执行
- ✅ 下次运行时间消失
- ✅ 状态徽章变为灰色

---

### 恢复任务 ▶️

**使用场景**:
- 恢复已暂停的任务
- 维护完成后重启任务

**操作步骤**:
1. 找到已暂停的任务
2. 点击右侧的 **"恢复"** 按钮
3. 确认状态变为 **"运行中"**
4. 任务恢复自动执行

**效果**:
- ✅ 任务恢复自动执行
- ✅ 显示下次运行时间
- ✅ 状态徽章变为绿色

---

### 立即执行 ⚡

**使用场景**:
- 不等待定时,立即执行一次任务
- 测试任务是否正常工作
- 手动触发数据更新

**操作步骤**:
1. 找到要执行的任务
2. 点击右侧的 **"立即执行"** 按钮
3. 任务立即开始执行
4. 可在 **"实时进度"** 标签页查看执行情况

**效果**:
- ✅ 任务立即执行一次
- ✅ 不影响原有的定时计划
- ✅ 可在实时进度中监控

## 📋 系统定时任务说明

### 1. 早间爬虫任务 🌅
- **任务ID**: `morning_crawl`
- **执行时间**: 每天 08:00
- **功能**: 运行所有爬虫,抓取最新资讯
- **预计耗时**: 10-20分钟

### 2. 午间爬虫任务 ☀️
- **任务ID**: `noon_crawl`
- **执行时间**: 每天 12:00
- **功能**: 运行所有爬虫,抓取午间更新
- **预计耗时**: 10-20分钟

### 3. 晚间爬虫任务 🌙
- **任务ID**: `evening_crawl`
- **执行时间**: 每天 18:00
- **功能**: 运行所有爬虫,抓取晚间资讯
- **预计耗时**: 10-20分钟

### 4. 每日AI简报生成 🤖
- **任务ID**: `daily_brief`
- **执行时间**: 每天 09:00
- **功能**: 生成昨日的AI简报
- **预计耗时**: 2-5分钟

### 5. 检查试用期到期 ⏰
- **任务ID**: `check_trial_expiry`
- **执行时间**: 每天 08:00
- **功能**: 检查即将到期的试用订阅,发送提醒
- **预计耗时**: < 1分钟

### 6. 处理过期试用订阅 🔒
- **任务ID**: `expire_trial_subscriptions`
- **执行时间**: 每天 01:00
- **功能**: 将已过期的试用订阅标记为过期
- **预计耗时**: < 1分钟

## 💡 使用技巧

### 1. 维护期间的操作
```
场景: 需要进行系统维护,暂时停止所有爬虫

步骤:
1. 暂停 morning_crawl
2. 暂停 noon_crawl
3. 暂停 evening_crawl
4. 维护完成后,逐个恢复任务
```

### 2. 测试新爬虫
```
场景: 添加了新的爬虫,想立即测试

步骤:
1. 点击 morning_crawl 的"立即执行"
2. 切换到"实时进度"标签页
3. 观察新爬虫的执行情况
4. 如有问题,在"爬取日志"中查看详细日志
```

### 3. 调整执行时间
```
场景: 发现某个时间段服务器负载过高

当前方案:
- 暂停冲突的任务
- 等待合适时间后手动触发

未来增强:
- 支持直接修改任务执行时间
```

## ⚠️ 注意事项

### 1. 暂停任务的影响
- ⚠️ 暂停爬虫任务会导致数据更新延迟
- ⚠️ 暂停AI简报任务会影响用户体验
- ⚠️ 暂停订阅管理任务可能影响计费

### 2. 立即执行的限制
- ⚠️ 同一任务不能同时执行多次
- ⚠️ 立即执行不会影响下次定时执行
- ⚠️ 频繁手动触发可能增加服务器负载

### 3. 权限要求
- 🔒 只有管理员可以访问此功能
- 🔒 所有操作都会记录日志
- 🔒 建议谨慎操作,避免影响系统稳定性

## 🔍 故障排查

### 问题1: 任务暂停后无法恢复
**可能原因**: 调度器异常
**解决方案**:
1. 检查后端日志
2. 重启后端服务
3. 联系技术支持

### 问题2: 立即执行没有反应
**可能原因**: 任务已在运行中
**解决方案**:
1. 检查"实时进度"标签页
2. 等待当前任务完成
3. 再次尝试触发

### 问题3: 下次运行时间不准确
**可能原因**: 时区配置问题
**解决方案**:
1. 检查服务器时区设置
2. 确认调度器时区配置(Asia/Shanghai)
3. 重启调度器服务
