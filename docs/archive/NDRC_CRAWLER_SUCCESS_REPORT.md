## 技术细节

### URL处理修复

**问题**: 相对路径 `./202604/t20260415_1404696.html` 处理错误

**修复前**:
```python
# 基类的process_url方法
return self.base_url.rstrip('/') + '/' + url.lstrip('/')
# 结果: https://www.ndrc.gov.cn/xwdt/tzgg/./202604/...
```

**修复后**:
```python
def process_url(self, url):
    """处理URL，补全相对路径"""
    if not url:
        return None
    
    # 如果是完整URL，直接返回
    if url.startswith('http://') or url.startswith('https://'):
        return url
    
    # 处理 ./ 开头的相对路径
    if url.startswith('./'):
        url = url[2:]  # 去掉 ./
    
    # 如果是相对路径，补全
    if url.startswith('/'):
        return f"https://www.ndrc.gov.cn{url}"
    
    # 其他情况，拼接base_url的目录部分
    base_dir = self.base_url.rsplit('/', 1)[0]
    return base_dir + '/' + url
```

**结果**: `https://www.ndrc.gov.cn/xwdt/tzgg/202604/t20260415_1404696.html` ✅
