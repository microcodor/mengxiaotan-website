### 3. API接口

#### 3.1 AI生成接口（3个）

**1. GET /api/reports/ai/templates**
- 功能：获取AI报告模板列表
- 权限：需要登录
- 返回：模板列表和AI服务状态

**2. POST /api/reports/ai/generate**
- 功能：使用AI生成报告内容
- 权限：管理员
- 参数：request_id
- 返回：Markdown格式的报告内容、摘要、Token使用量

**3. POST /api/reports/ai/generate-and-save**
- 功能：使用AI生成报告并保存为文件
- 权限：管理员
- 参数：request_id
- 返回：文件ID、文件名、Token使用量
- 自动更新申请状态为已完成

#### 3.2 管理员接口（4个）

**1. GET /api/reports/admin/requests**
- 功能：获取所有报告申请
- 权限：管理员
- 参数：status（可选）
- 返回：申请列表

**2. GET /api/reports/admin/statistics**
- 功能：获取统计信息
- 权限：管理员
- 返回：各状态的申请数量

**3. POST /api/reports/admin/requests/:id/assign**
- 功能：分配报告
- 权限：管理员
- 参数：assigned_to
- 返回：成功消息

**4. PUT /api/reports/admin/requests/:id/status**
- 功能：更新申请状态
- 权限：管理员
- 参数：status, rejected_reason
- 返回：成功消息

**5. POST /api/reports/admin/requests/:id/upload**
- 功能：上传报告文件
- 权限：管理员
- 参数：file（multipart/form-data）
- 返回：文件ID和文件名

## 🚀 使用流程

### 管理员使用流程

#### 1. 查看申请
1. 进入管理后台
2. 点击"报告管理"
3. 查看待处理申请
4. 使用筛选功能

#### 2. 分配报告
1. 点击"分配"按钮
2. 输入编写人员ID
3. 确认分配
4. 状态变为"已分配"

#### 3. AI生成报告
1. 选择申请
2. 调用AI生成接口
3. 预览生成内容
4. 确认保存
5. 自动更新状态为"已完成"

#### 4. 人工上传
1. 点击"上传报告"
2. 选择文件（PDF/Word）
3. 确认上传
4. 自动更新状态为"已完成"

#### 5. 拒绝申请
1. 点击"拒绝"按钮
2. 填写拒绝原因
3. 确认拒绝
4. 状态变为"已拒绝"

## 📝 API使用示例

### 1. 获取AI模板
```bash
curl -X GET http://localhost:5000/api/reports/ai/templates \
  -H "Authorization: Bearer YOUR_TOKEN"
```

### 2. 生成报告内容
```bash
curl -X POST http://localhost:5000/api/reports/ai/generate \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"request_id": 1}'
```

### 3. 生成并保存报告
```bash
curl -X POST http://localhost:5000/api/reports/ai/generate-and-save \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"request_id": 1}'
```
