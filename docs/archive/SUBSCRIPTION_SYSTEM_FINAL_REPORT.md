## 📈 技术架构

### 后端技术栈
- **框架**: Flask + Flask-Smorest
- **数据库**: MySQL + SQLAlchemy
- **认证**: JWT (Flask-JWT-Extended)
- **缓存**: Redis
- **定时任务**: APScheduler
- **数据格式**: JSON

### 前端技术栈
- **框架**: React 18 + TypeScript
- **状态管理**: React Query (TanStack Query)
- **HTTP客户端**: Axios
- **UI组件**: Tailwind CSS
- **图标**: Lucide React
- **路由**: React Router v6
- **图表**: Recharts

### 数据库设计
**新增表**:
1. `monitoring_rules` - 监测规则
2. `monitoring_alerts` - 预警记录
3. `simulation_scenarios` - 模拟场景
4. `simulation_results` - 模拟结果
5. `report_requests` - 报告申请
6. `report_files` - 报告文件
7. `report_quota_usage` - 配额使用记录

## 🚀 部署指南

### 1. 环境要求
- Python 3.8+
- Node.js 16+
- MySQL 8.0+
- Redis 6.0+

### 2. 数据库初始化
```bash
cd backend
python init_db.py
python migrate_subscription_plans.py
python create_simulation_tables.py
python create_report_tables.py
python create_monitoring_tables.py
```

### 3. 后端启动
```bash
cd backend
pip install -r requirements.txt
python run.py
```

### 4. 前端启动
```bash
cd frontend
npm install
npm run dev
```
