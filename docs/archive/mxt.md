# 蒙小碳 · 能源站 —— PC响应式设计升级与全源抓取方案


## 一、视觉设计策略：AI科技感 × 能源专业风

### 1.1 设计风格定位

2026年的PC能源站设计，应融合以下三大方向：

**玻璃态+深色基底+霓虹绿点缀**：Apple iOS、SaaS科技网站和能源数据大屏都证实了“深色模式搭配霓虹色”和“玻璃质感透明磨砂效果”的流行趋势。能源行业的最佳实践也指向**深蓝/深黑底色 + 荧光绿/电光蓝强调色**的组合——深色基底降低视觉疲劳、突出数据可视化元素，荧光绿用于核心数字指标，形成强烈视觉焦点，契合能源行业的沉稳与科技感。

**AI风格设计趋势**：2026年网页设计由AI驱动界面、沉浸式叙事和包容性体验三大趋势主导。包括：
- **AI驱动的自适应UI**：根据用户角色动态调整内容优先级（员工看到日报摘要、高管看到数据看板）
- **玻璃拟态升级版**：透明度+模糊效果+霓虹光效，增强科技感与层次感，适用于卡片、侧边栏、弹窗
- **Bento Grids布局**：将信息模块化排列，兼顾可扫读性与视觉秩序感，2026年成为重点布局趋势
- **沉浸式滚动**：滚动触发的微交互动画（如能源数据动态增长、光效流动），营造探索未来科技的体验

**能源行业专属元素**：
- 动态数据可视化：实时能源流动画、产能趋势折线图、碳排放数字卡片
- 科技感边框与分割线：圆角、渐变、光效细节处理，强化现代科技感
- 高质量实景影像：无人机航拍项目现场、光伏/风电实景，展现规模与专业度

### 1.2 配色方案

| 用途 | 颜色 | 说明 |
|------|------|------|
| **背景基底** | 深色主题（#0A0E17 ～ #111827） | 或提供亮色/深色切换，深色默认更显科技感、降低视觉疲劳 |
| **主色调** | 生态绿（#10B981 / #059669） + 科技蓝（#0EA5E9 / #3B82F6） | 绿=清洁能源/可持续发展，蓝=科技/稳定/信任 |
| **强调色** | 霓虹绿（#22C55E）+ 活力橙（#F59E0B）+ 电光蓝（#06B6D4） | 用于核心数字指标高亮、CTA按钮、数据图表重点标注 |
| **卡片背景** | 玻璃态半透明（rgba(255,255,255,0.03) ～ 0.08）+ 模糊 backdrop-blur | 营造轻盈通透的层次感 |
| **图表色系** | 多组区分色（绿/蓝/橙/青）保证不同维度的视觉识别性 | ECharts/Recharts 配色体系 |

### 1.3 视觉组件风格

### 3.8 抓取策略与保障机制

**双轨保障机制**：

1. **主轨道（结构化抓取）** ：
   - 采用Scrapy爬虫框架，对上述P0/P1级别来源进行每日定时抓取
   - 配置User-Agent轮换、请求延迟、IP代理池，规避反爬
   - 设置超时重试机制（最多3次）
   - 抓取频率：核心源每日2次（8:00/20:00），一般源每日1次

2. **备用轨道（AI联网搜索补全）** ：
   - 当固定源抓取失败或内容不足（低于设定阈值）时，自动触发MiniMax联网搜索能力
   - 搜索关键词：发改委+能源+煤炭+电力+新能源+今日
   - 搜索结果自动去重、分类、摘要生成后入库

3. **数据质量控制** ：
   - 入库前自动去重（基于URL哈希 + 标题相似度）
   - 自动分类打标（基于关键词规则 + AI辅助判断）
   - 来源权威性评分（官媒/部委官网权重最高，自媒体/转载权重较低）
   - 关键数据（如产量、价格）设置异常值检测，超出合理范围自动标记人工审核
