## 🎯 核心功能实现

### 1. 订阅服务类 (SubscriptionService)

**文件**: `backend/app/services/subscription_service.py`

**核心方法**:

#### 1.1 试用期管理
```python
# 检查用户是否可以试用
can_start_trial(user_id) -> (bool, str)

# 创建试用订阅（7天）
create_trial_subscription(user_id) -> Dict

# 检查即将到期的试用订阅
check_trial_expiry() -> list

# 将已过期的试用订阅标记为过期
expire_trial_subscriptions() -> int
```

#### 1.2 付费订阅管理
```python
# 创建付费订阅（支持月付/年付）
create_paid_subscription(user_id, plan_id, payment_cycle) -> Dict

# 计算订单金额
calculate_order_amount(plan_id, payment_cycle) -> float

# 计算订阅时长
calculate_duration_days(plan_id, payment_cycle) -> int
```

#### 1.3 订阅状态查询
```python
# 获取用户订阅状态
get_user_subscription_status(user_id) -> Dict
```

**业务规则**:
- 每个用户只能试用一次
- 试用期固定7天
- 基础版月付：¥39/30天
- 基础版年付：¥468/365天（赠1个月）
- 免费试用自动创建订阅

### 2. API更新

**文件**: `backend/app/api/subscriptions.py`

#### 2.1 新增接口

**GET /api/subscriptions/status**
- 获取用户订阅状态（包括试用资格）
- 返回：是否有订阅、套餐信息、剩余天数、是否可试用

**响应示例**:
```json
{
  "success": true,
  "data": {
    "has_subscription": true,
    "subscription_id": 1,
    "plan_name": "免费订阅",
    "is_trial": true,
    "days_remaining": 5,
    "status": "active"
  }
}
```

#### 2.2 更新接口

**POST /api/subscriptions/subscribe**
- 支持试用订阅和付费订阅
- 自动识别套餐类型
- 支持支付周期参数

**POST /api/subscriptions/orders**
- 支持年付逻辑
- 自动计算实际金额和时长
- 免费试用自动创建订阅

### 3. 定时任务

**文件**: `backend/app/scheduler.py`

#### 3.1 新增任务

**任务1: 检查试用期到期**
- 时间：每天 08:00
- 功能：检查即将到期的试用订阅（1天内）
- 操作：发送提醒消息，引导升级

**任务2: 处理过期试用订阅**
- 时间：每天 01:00
- 功能：将已过期的试用订阅标记为过期
- 操作：更新订阅状态为 `expired`

**任务3: 生成每日简报**
- 时间：每天 09:00（从07:00调整）
- 功能：生成AI简报并推送

## 🔄 业务流程

### 试用订阅流程
```
用户注册 
  → 检查试用资格 
  → 创建试用订阅（7天）
  → 每日检查到期（8:00）
  → 发送提醒（到期前1天）
  → 自动过期（凌晨1:00）
  → 引导升级
```

### 付费订阅流程
```
用户选择套餐
  → 选择支付周期（月付/年付）
  → 计算金额和时长
  → 创建订单
  → 支付确认
  → 创建订阅
  → 开通服务
```

### 年付优惠流程
```
用户选择基础版
  → 选择年付
  → 金额：¥468（原价¥468）
  → 时长：365天（12个月 + 赠1个月）
  → 相当于：¥36/月
  → 节省：¥60/年
```
