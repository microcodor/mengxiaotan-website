## 🔍 后端API测试

### 测试API端点

#### 1. 获取完整企业画像
```bash
curl -X GET "http://localhost:5000/api/company-profile/1" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

**预期响应**:
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "company_id": 1,
    "company_name": "测试企业",
    "overall_score": 90,
    "competitiveness": {...},
    "risks": {...},
    "opportunities": {...},
    "summary": "...",
    "data_sources": [...],
    "generated_at": "2026-04-16T16:00:00"
  }
}
```

#### 2. 获取企业画像摘要
```bash
curl -X GET "http://localhost:5000/api/company-profile/1/summary" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

#### 3. 导出企业画像
```bash
curl -X GET "http://localhost:5000/api/company-profile/1/export?format=json" \
  -H "Authorization: Bearer YOUR_TOKEN"
```
