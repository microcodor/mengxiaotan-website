## 🔧 技术实现

- **React** - UI框架
- **TypeScript** - 类型安全
- **React Query** - 数据获取和缓存
- **React Router** - 路由管理
- **Lucide React** - 图标库
- **Tailwind CSS** - 样式框架

### 后端技术栈
- **Flask** - Web框架
- **SQLAlchemy** - ORM
- **MySQL** - 数据库
- **JWT** - 身份认证

### 数据流
```
用户访问页面
    ↓
React Query 发起请求
    ↓
API: GET /api/company-profile/{id}
    ↓
CompanyProfileService 生成画像
    ↓
返回JSON数据
    ↓
前端渲染展示
```
