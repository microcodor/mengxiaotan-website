### 2. 爬虫管理页面 - 定时任务管理功能
**状态**: ✅ 已完成

**实现内容**:

#### 后端API (backend/app/api/crawler.py)
新增以下API接口:

1. **GET `/api/crawler/schedule`** - 获取所有定时任务
   - 返回所有定时任务列表
   - 包含任务状态(运行中/已暂停)
   - 显示下次运行时间
   - 任务类型分类(爬虫/AI简报/订阅管理)

2. **POST `/api/crawler/schedule/<job_id>/pause`** - 暂停定时任务
   - 暂停指定的定时任务
   - 任务不会再自动执行

3. **POST `/api/crawler/schedule/<job_id>/resume`** - 恢复定时任务
   - 恢复已暂停的定时任务
   - 任务恢复自动执行

4. **POST `/api/crawler/schedule/<job_id>/trigger`** - 立即触发任务
   - 立即执行一次定时任务
   - 不影响原有的定时计划

#### 前端UI (frontend/src/pages/admin/Crawler.tsx)
新增"定时任务"标签页:

**功能特性**:
- 📋 显示所有定时任务列表(6个任务)
  - 早间爬虫任务 (每天 08:00)
  - 午间爬虫任务 (每天 12:00)
  - 晚间爬虫任务 (每天 18:00)
  - 每日AI简报生成 (每天 09:00)
  - 检查试用期到期 (每天 08:00)
  - 处理过期试用订阅 (每天 01:00)

- 🏷️ 任务类型标签
  - 🔵 爬虫任务 (crawler)
  - 🟣 AI简报 (ai_brief)
  - 🟡 订阅管理 (subscription)

- 📊 任务信息显示
  - 任务名称和ID
  - 运行状态(运行中/已暂停)
  - 触发器配置(Cron表达式)
  - 下次运行时间

- 🎮 任务控制按钮
  - ▶️ 恢复 - 恢复已暂停的任务
  - ⏸️ 暂停 - 暂停正在运行的任务
  - ⚡ 立即执行 - 手动触发任务执行

**UI设计**:
- 使用玻璃态卡片设计
- 状态徽章(绿色=运行中, 灰色=已暂停)
- 实时刷新(每5秒)
