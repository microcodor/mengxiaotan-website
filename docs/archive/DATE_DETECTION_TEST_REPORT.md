## 功能实现

### 1. 日期提取功能 (`extract_date_from_content`)
从文章内容和标题中提取发布日期，支持多种日期格式：

- **ISO格式**: `2026-04-16`
- **中文格式**: `2026年04月16日`
- **斜杠格式**: `2026/04/16`
- **点号格式**: `2026.04.16`
- **时间戳格式**: `2026-04-16 10:30:00`
- **关键词**: `今天`、`今日`

### 2. 当日文章检测功能 (`is_today_article`)
检查文章是否是今天发布的：
- 返回 `(True, date)` - 确认是今天的文章
- 返回 `(False, date)` - 确认不是今天的文章
- 返回 `(None, None)` - 无法确定（无日期信息）

### 3. 日期验证规则
- 不能是未来日期
- 不能太久远（超过365天）
- 优先匹配最早出现的有效日期

## 爬虫集成

日期检测功能已集成到爬虫基类 `crawl4ai_base.py` 的详情页爬取流程中：

```python
# 详情页爬取流程
1. 提取文章内容
2. 验证内容质量（404、反爬、非详情页等）
3. 检查是否是今天的文章 ← 新增
   - 是今天的文章 → 保存到数据库
   - 不是今天的文章 → 跳过
   - 无法确定日期 → 给出警告但仍然保存
4. 保存到数据库
```

## 处理策略

### 明确是今天的文章
- ✅ 保存到数据库
- 日志：`✓ 当日文章(2026-04-16)`

### 明确不是今天的文章
- ⏭️ 跳过，不保存
- 日志：`⏭️ 跳过: 非当日文章(2026-04-15)`

### 无法确定日期
- ⚠️ 给出警告但仍然保存
- 日志：`⚠️ 警告: 无法提取发布日期，仍然保存`
- 原因：避免因日期提取失败而丢失有效文章
