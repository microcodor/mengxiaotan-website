## 问题总结

### 主要问题
1. **CSS选择器不准确**: 大部分爬虫的CSS选择器没有匹配到文章列表
2. **Markdown提取不精确**: 提取到大量导航链接，而不是文章链接
3. **详情页内容提取**: Markdown提取的内容不完整

### 根本原因
- 没有实际查看网站的HTML结构就编写选择器
- 使用了通用的选择器模式，但不同网站结构差异很大
- Markdown提取作为备用方案，但对于复杂网站效果不好

## 解决方案

### 方案1: 优化CSS选择器（推荐）
需要针对每个网站实际查看HTML结构，编写精确的CSS选择器。

**步骤**:
1. 访问网站，查看页面源代码
2. 找到文章列表的实际CSS类名和结构
3. 更新 `list_schema` 中的 `baseSelector`
4. 测试验证

### 方案2: 改进Markdown过滤
在Markdown提取后，添加更严格的过滤规则。

**改进点**:
1. 过滤URL中包含特定关键词的链接（如 `/about/`, `/contact/`, `/sitemap/`）
2. 过滤标题太短的链接（<10个字符）
3. 只保留URL中包含日期或文章ID的链接

### 方案3: 使用详情页CSS选择器
对于详情页，不使用Markdown，而是使用CSS选择器提取内容。

**优点**:
- 更精确的内容提取
- 可以提取特定字段（标题、日期、作者等）
- 避免提取导航和广告内容
