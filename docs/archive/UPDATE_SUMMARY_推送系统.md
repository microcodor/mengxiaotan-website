## 📋 业务流程

### 用户配置流程

```
1. 用户登录系统
   ↓
2. 访问推送设置页面 (/push-settings)
   ↓
3. 填写企业微信用户 ID
   ↓
4. 点击"发送测试消息"验证

   ↓
6. 保存设置
   ↓

```

### 推送执行流程

```
1. 触发推送（定时/手动）
   ↓
2. 获取目标用户列表
   ↓
3. 获取企业微信 Access Token
   ↓
4. 格式化推送内容
   ↓
5. 调用企业微信 API 发送
   ↓
6. 记录推送日志
   ↓
7. 更新推送状态
```

## 🔧 技术实现

### 后端技术栈
- **Flask-Smorest**: RESTful API 框架
- **Requests**: HTTP 请求库（调用企业微信 API）
- **APScheduler**: 定时任务调度
- **SQLAlchemy**: 数据库 ORM

### 企业微信 API
- **获取 Token**: `GET /cgi-bin/gettoken`
- **发送消息**: `POST /cgi-bin/message/send`
- **消息类型**: text, markdown, textcard

### 前端技术栈
- **React 18**: UI 框架
- **TanStack Query**: 数据获取和缓存
- **Lucide React**: 图标库

## 🚀 使用说明

### 1. 配置企业微信

编辑 `backend/.env`：

```env
WECHAT_WORK_CORPID=your-corp-id
WECHAT_WORK_CORPSECRET=your-corp-secret
WECHAT_WORK_AGENTID=your-agent-id
```

### 2. 重启服务

```bash
./stop.sh
./start.sh
```

### 3. 用户配置

1. 访问 http://localhost:5173/push-settings
2. 填写企业微信用户 ID
3. 点击"发送测试消息"
4. 保存设置

### 4. 管理员推送

1. 访问 http://localhost:5173/admin/broadcast
2. 点击"创建推送"或"推送今日简报"
3. 查看推送状态

## 📝 配置获取指南

### 获取企业微信配置

1. **登录企业微信管理后台**
   - 访问：https://work.weixin.qq.com/

2. **获取企业 ID (CorpID)**
   - 进入「我的企业」
   - 在「企业信息」中找到「企业 ID」

3. **创建应用**
   - 进入「应用管理」→「应用」→「创建应用」
   - 填写应用名称：蒙小碳·能源站
   - 选择可见范围
   - 记录「AgentId」和「Secret」

4. **获取用户 ID**
   - 进入「通讯录」
   - 查看成员详情
   - 用户 ID 通常是工号或邮箱前缀

详细说明请查看 `PUSH_GUIDE.md`

## 🐛 已知限制

1. **推送渠道**
   - 当前仅支持企业微信
   - 需要企业微信账号

2. **消息类型**
   - 支持文本、Markdown、文本卡片
   - 不支持图片、文件等富媒体

3. **推送频率**
   - 企业微信有频率限制
   - 建议合理控制推送频率

4. **用户配置**
   - 需要用户手动配置企业微信 ID
   - 需要管理员提供用户 ID
