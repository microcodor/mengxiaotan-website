## 🚀 部署指南

### 1. 环境要求
```bash
# 后端
Python 3.8+
MySQL 8.0+
Redis 6.0+

# 前端
Node.js 16+
npm 8+
```

### 2. 数据库初始化
```bash
cd backend
python init_db.py
python migrate_subscription_plans.py
python create_simulation_tables.py
python create_report_tables.py
python create_monitoring_tables.py
```

### 3. 环境变量配置
```bash
# 复制示例配置
cp .env.example .env

# 编辑配置文件
# 必须配置：
# - DATABASE_URL
# - REDIS_URL
# - JWT_SECRET_KEY
# - OPENAI_API_KEY（用于AI生成）
```

### 4. 后端启动
```bash
cd backend
pip install -r requirements.txt
python run.py
```

### 5. 前端启动
```bash
cd frontend
npm install
npm run dev
```
