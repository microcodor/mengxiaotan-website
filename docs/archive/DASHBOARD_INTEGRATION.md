## 🔌 数据来源

### API调用

仪表盘同时调用两个API：

1. **原有仪表盘API**
   ```
   GET /api/admin/dashboard
   ```
   返回：用户数、文章数、分类统计等

2. **监控API**（新增）
   ```
   GET /api/monitor/statistics?days=7
   GET /api/monitor/health
   GET /api/monitor/failures?limit=5
   ```
   返回：监控统计、健康状态、失败记录

### 数据整合

```typescript
const { data: dashboard } = useQuery({
  queryKey: ['admin-dashboard'],
  queryFn: () => api.get('/admin/dashboard'),
})

const { data: monitorData, refetch: refetchMonitor } = useQuery({
  queryKey: ['dashboard-monitor'],
  queryFn: async () => {
    const [stats, health, failures] = await Promise.all([
      api.get('/monitor/statistics?days=7'),
      api.get('/monitor/health'),
      api.get('/monitor/failures?limit=5')
    ])
    return { stats, health, failures: failures.failures || [] }
  },
  refetchInterval: autoRefresh ? 60000 : false,
})
```

## ⚡ 性能优化

### 1. 并行请求
- 使用 `Promise.all` 并行请求3个监控API
- 减少总等待时间

### 2. 智能刷新
- 只刷新监控数据，不刷新仪表盘基础数据
- 可选的自动刷新，避免不必要的请求

### 3. 条件渲染
- 只在有数据时渲染对应面板
- 失败记录为空时不显示告警面板

## 🚀 使用指南

### 查看仪表盘

1. 登录管理后台
2. 访问 `/admin` 或点击"仪表盘"菜单
3. 页面自动加载所有监控数据

### 刷新数据

**自动刷新**：
- 默认开启，每分钟自动刷新
- 取消勾选"自动刷新"可关闭

**手动刷新**：
- 点击右上角"刷新"按钮
- 立即更新监控数据

### 查看详细信息

- 点击侧边栏"监控告警"菜单
- 进入 `/admin/monitor` 查看详细监控数据
